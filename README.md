# Контроллер климатической камеры на ESP32 (Версия 1.1.2)

Прошивка для автоматического поддержания микроклимата (температуры, влажности, воздухообмена) в климатической камере / шкафу созревания сыров и колбас.

Разработано для платы **ESP32 Dev Module (30-pin / 38-pin)** с дисплеем **ST7789 IPS 240×240 (SPI)** и датчиком **SHT30 / SHT31 (I²C)**.

---

## Ключевые особенности версии 1.1.2

1. **Плавная работа дисплея без миганий:**
   - Отключен циклический сброс контроллера ST7789 каждые 120 секунд. Экран обновляется исключительно по тайловым изменениям буфера кадра (12 полос по 20 пикселей).
   - Аварийный сброс контроллера срабатывает только при фактическом застывании SPI-передачи более чем на 3 секунды.
2. **Отказоустойчивый опрос датчика SHT30 (`Sht30Reliable`):**
   - Одновременное чтение температуры и влажности за одну транзакцию.
   - Аппаратная проверка контрольной суммы CRC8 для каждого пакета.
   - Аппаратный таймаут шины Wire и процедура расклинивания шины 9 тактами SCL при зависаниях.
3. **Безопасная логика исполнительных механизмов:**
   - **Холодильник (IN1):** аппаратная задержка пуска 5 минут (300 с) после подачи питания и между циклами работы для защиты компрессора от пуска под давлением.
   - **Увлажнитель (IN2):** циклический режим (20 секунд работы / 2 минуты паузы) для равномерного распределения влаги по объёму камеры.
   - **Осушитель (IN3):** полностью отключён.
   - **ТЭН нагрева (IN4):** двухпозиционное релейное управление с настраиваемым гистерезисом.
   - **Вентилятор циркуляции:** аппаратный ШИМ 25 кГц на GPIO18 с обратной связью по тахометру (GPIO19) и PI-регулятором оборотов (RPM).

## Назначение выводов (Распиновка)

| Узел / Модуль | Пин ESP32 | Примечание |
|---|---|---|
| **Реле IN1** (Холод) | GPIO 26 | Активный уровень LOW |
| **Реле IN2** (Увлажнение) | GPIO 27 | Активный уровень LOW |
| **Реле IN3** (Осушитель) | GPIO 14 | Постоянно выключен |
| **Реле IN4** (Нагрев) | GPIO 12 | Активный уровень LOW |
| **ШИМ вентилятора** | GPIO 18 | Частота 25 кГц, инвертированный ШИМ |
| **Тахометр вентилятора** | GPIO 19 | Прерывание по спаду импульса |
| **SHT30 SDA** | GPIO 21 | Шина I²C (аппаратные подтяжки 4.7 кОм) |
| **SHT30 SCL** | GPIO 22 | Шина I²C (аппаратные подтяжки 4.7 кОм) |
| **TFT MOSI (SDA)** | GPIO 23 | Аппаратный VSPI |
| **TFT SCLK (SCL)** | GPIO 18* / 5 | В зависимости от трассировки платы |
| **TFT CS** | GPIO 5 / 15 | Чипселект дисплея |
| **TFT DC** | GPIO 25 | Данные / Команда |
| **TFT RST** | GPIO 13 | Аппаратный сброс |
| **Энкодер CLK / DT** | GPIO 32 / 33 | Опрос с подавлением дребезга |
| **Энкодер SW (Кнопка)**| GPIO 35 | Вход без внутренней подтяжки (нужен внешний резистор) |

## Инструкция по сборке в Arduino IDE

1. Установите ядро **ESP32 by Espressif Systems** (рекомендуется ветка 2.0.17).
2. Выберите плату: `ESP32 Dev Module`.
3. Установите библиотеку **TFT_eSPI** (версия 2.5.x).
4. Скопируйте файл `TFT_eSPI_setup/User_Setup.h` в папку библиотеки `Arduino/libraries/TFT_eSPI/User_Setup.h` (заменив стандартный файл).
5. Откройте скетч `ClimateCamera_1_1_2_IDE1819/ClimateCamera_1_1_2_IDE1819.ino`.
6. Скомпилируйте и прошейте плату.
