# ESP32-Climate-Camera v1.2.0

Исходники контроллера ESP32 Dev Module с ST7789 240×240, SHT30/31, Wi-Fi AP+STA, Web UI и Web OTA.

Сетевой модуль выделен в задачу Core 0; климат и экран остаются в loop. Веб-управление использует команды с подтверждением; перед OTA реле отключаются. Добавлен максимум хода компрессора 40 минут. Циклический сброс дисплея отключён.

Требуются Arduino-ESP32 2.0.17, TFT_eSPI и профиль дисплея из архива. Первая прошивка с OTA-разметкой — по USB. Перед эксплуатацией создайте Secrets.h из примера, смените пароли, проверьте активный HIGH реле и выполните стендовые испытания.

Это релиз исходников: готовых BIN нет, полная сборка для ESP32 и аппаратные испытания не проводились. Точные результаты проверок приведены в BUILD_REPORT.md.
