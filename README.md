# ESP32 Climate Camera — Прошивка контроллера климатической камеры

Система автоматического контроля температуры, влажности и воздухообмена в климатической камере на базе микроконтроллера **ESP32 Dev Module** и цветного IPS-дисплея **ST7789 (240x240)**.

---

## 📌 Версия 1.0.4

### Ключевые изменения версии 1.0.4:
1. **Удалён канал осушителя (IN3):** В связи с отсутствием осушителя в контуре камеры соответствующий алгоритм и управление реле отключены.
2. **Надёжный I2C-драйвер SHT30/SHT31 (`Sht30Reliable`):**
   - Контроль CRC8 для температуры и влажности.
   - Защита от зависания шины I2C и автовосстановление при сбоях питания датчика.
   - Разнесённый опрос (20 мс интервал конверсии) без блокировки основного цикла программы.
3. **Холодильный контур:** Защита компрессора (минимальный интервал отдыха и задержка старта — 5 минут).
4. **Увлажнение:** Импульсный режим (20 сек работы / 120 сек паузы) для равномерного насыщения объема влагой.
5. **Вентиляция:** Аппаратный ШИМ 25 кГц с измерением оборотов тахометра (Tach).

## 💻 Сборка и прошивка (Arduino IDE 1.8.19)

1. Установите ядро **esp32 by Espressif Systems** версии **2.0.17** (Инструменты -> Плата -> Менеджер плат).
2. Выберите плату: **ESP32 Dev Module**.
3. Установите библиотеку **TFT_eSPI** (версии 2.5.x).
4. Скопируйте файл `TFT_eSPI_setup/User_Setup.h` в папку установленной библиотеки:  
   `Arduino/libraries/TFT_eSPI/User_Setup.h` (заменив существующий).
5. Откройте файл `ClimateCamera_1_0_4_IDE1819/ClimateCamera_1_0_4_IDE1819.ino`.
6. Выполните компиляцию и загрузите прошивку в микроконтроллер.

## 📦 Готовые скомпилированные бинарники (`binaries/`)

Для быстрой прошивки без среды разработки в папке `binaries` подготовлены:
- `ClimateCamera_1_0_4.app.bin` — образ приложения для OTA или прошивки по смещению `0x10000`.
- `ClimateCamera_1_0_4.full.bin` — полный дамп для прошивки с адреса `0x0000`.
