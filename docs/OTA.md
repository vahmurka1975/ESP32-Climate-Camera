# Web OTA — v1.2.0

## Предварительная подготовка

Первая загрузка выполняется по USB с разделами, содержащими два OTA-слота приложения. Рекомендуемая конфигурация для классического ESP32 с 4 MB flash — Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS). Прошивка через браузер не меняет таблицу разделов. Если текущий образ установлен в Huge APP / No OTA, сначала измените схему и прошейте по USB.

## Файл

Скомпилируйте этот скетч для ESP32 Dev Module и выбранной схемы. Используйте бинарник именно приложения (`*.ino.bin` / app BIN). Не используйте merged/full, bootloader или partitions. Размер приложения должен помещаться в OTA-слот. В данный архив никакие готовые бинарники не включены.

## Порядок

1. Убедитесь, что есть надёжное питание и безопасно остановить оборудование.
2. Откройте `/update` и войдите с реквизитами CC_ADMIN_USER / CC_ADMIN_PASS из Secrets.h.
3. Выберите файл .bin приложения и подтвердите остановку.
4. Сетевая задача запросит EnterOta у климатического ядра. Только после ответа «выходы выключены» будет вызван Update.begin.
5. Дождитесь полного завершения. Не отключайте питание и не закрывайте соединение во время записи.
6. После успешной валидации новый образ выбирается штатной библиотекой Update и ESP32 перезагружается. Действует обычный автозапуск с обязательной задержкой компрессора 5 минут.

При ошибке, отмене или тайм-ауте запись прерывается. Перезагрузка не планируется. Система остаётся выключенной; проверьте состояние через `/` и запустите вручную при отсутствии аварий. Ошибка подтверждения от климатического ядра запрещает запись. При исчезновении связи не делайте вывод о результате по одному браузерному тайм-ауту: проверьте устройство и Serial.

## Ограничения безопасности

HTTP Basic Auth и токен защищают доступ в доверенной локальной сети, но не шифруют трафик. Отдельная криптографическая подпись приложения и автоматический rollback после неудачной загрузки новой прошивки этим проектом не настраиваются. Проверка заголовка/целостности Update не подтверждает, что пользователь выбрал правильную аппаратную сборку. За совместимость образа отвечает оператор. Для обновлений вне локальной сети используйте защищённый внешний канал, не открытый HTTP-порт.
