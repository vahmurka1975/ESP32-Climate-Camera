# История изменений

## v1.2.0 — 2026-10-12

Пакет впервые заново сформирован из доступных исходников с единым номером v1.2.0. Ссылки предыдущей переписки и переименованные архивы не используются.

### Добавлено
- Сетевой модуль NetworkServer.cpp: AP+STA, периодическое повторное подключение, mDNS.
- Встроенный Web UI мониторинга/настроек и страница OTA, без внешних зависимостей.
- GET /api/status, GET/POST /api/config, POST /api/control.
- HTTP Basic Auth и токен изменяющих запросов.
- Обмен между задачами через очереди с подтверждением и снимком состояния.
- Отключение исполнительных выходов с подтверждением перед OTA; отказ в записи без подтверждения.
- Перезагрузка только после успешного завершения OTA; остановленная автоматика при ошибке.
- Личные сетевые парамтры вынесены в игнорируемый Secrets.h; публичный пример без домашнего пароля.
- Ограничение непрерывной работы компрессора 40 минут и пауза после достижения лимита.
- Настройка Task WDT на 8 секунд для основного цикла.
- Манифест, SHA-256 и проверки целостности архива.

### Изменено
- Единый FW_VERSION 1.2.0, профиль ST7789 240x240 и папка скетча ClimateCamera_1_2_0_IDE1819.
- Отключён периодический сброс дисплея; условие не срабатывает при нулевом интервале.
- Документация исправлена: штатный HTTP-сервер синхронный, работает в отдельной задаче.

### Сохранено из предоставленного исходника
- GPIO, активный HIGH релейных выходов, IN3 выключен.
- Увлажнение 20 с / 120 с, задержки компрессора 5 минут и минимум работы 2 минуты.
- Sht30Reliable с CRC8 и восстановлением I2C, энкодер, кириллица, тайловая графика.
- ПИ-регулирование, PWM 25 кГц, тахометр, формат климатических настроек NVS.

### Статус
Полная компиляция для ESP32 и аппаратные испытания не выполнены. Сведения о предыдущих номерах версий приведены только как происхождение исходника, не как новые подтверждённые выпуски.
