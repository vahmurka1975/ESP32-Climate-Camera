# ESP32 Climate Camera (Версия 1.0.5)

Автономный контроллер климатической камеры на базе ESP32 с TFT-дисплеем ST7789 (240×240), датчиком температуры и влажности SHT30/SHT31 и аппаратным ШИМ вентилятора.

## Ключевые особенности версии 1.0.5
1. **Task Watchdog Timer (WDT 8 сек):** защита от аппаратных зависаний при помехах от реле и силовых цепей.
2. **Защита компрессора по времени:** ограничение непрерывной работы холодильника до 40 минут с последующей обязательной 5-минутной защитной паузой.
3. **Fail-Safe отключение нагрузок:** при потере связи с датчиком температуры/влажности все реле немедленно обесточиваются.
4. **Надёжная шина I²C:** драйвер `Sht30Reliable` со сбросом зависшей шины тактовыми импульсами и расчётом CRC8.
5. **Вентилятор с аппаратным ШИМ 25 кГц:** плавное PI-регулирование скорости с контролем тахометра.
6. **Увлажнитель:** циклический алгоритм (20 с работа / 120 с пауза) для исключения переувлажнения и конденсата.

## Распиновка GPIO

| Периферия | Пин ESP32 | Примечание |
| :--- | :--- | :--- |
| **Реле IN1 (Холодильник)** | GPIO 19 | Активный LOW |
| **Реле IN2 (Увлажнитель)** | GPIO 18 | Активный LOW |
| **Реле IN3** | GPIO 5 | Не используется (отключен) |
| **Реле IN4 (Питание вентилятора)** | GPIO 17 | Активный LOW |
| **SHT30 SDA** | GPIO 21 | I²C шина (с подтяжкой) |
| **SHT30 SCL** | GPIO 22 | I²C шина |
| **Вентилятор PWM** | GPIO 4 | 25 кГц, аппаратный ШИМ |
| **Вентилятор TACH** | GPIO 16 | Тахометр (прерывания) |
| **Энкодер A / B** | GPIO 32 / 33 | Управление меню |
| **Кнопка энкодера** | GPIO 34 | Вход |
| **Дисплей ST7789 CS** | GPIO 15 | SPI |
| **Дисплей DC** | GPIO 25 | Data/Command |
| **Дисплей RST** | GPIO 13 | Reset |
| **Дисплей SCLK / MOSI** | GPIO 14 / 27 | Аппаратный HSPI (20 МГц) |

## Сборка и прошивка (Arduino IDE 1.8.19 / 2.x)

1. Установите поддержку плат ESP32: **ESP32 by Espressif Systems** (рекомендуется версия `2.0.17`).
2. Плата в меню: **ESP32 Dev Module**.
3. Установите библиотеку **TFT_eSPI** (Bodmer).
4. Скопируйте файл `TFT_eSPI_setup/User_Setup.h` в папку библиотеки `TFT_eSPI` (заменив стандартный файл).
5. Откройте скетч `ClimateCamera_1_0_5_IDE1819/ClimateCamera_1_0_5_IDE1819.ino`.
6. Подключите ESP32 по USB и нажмите **Загрузка (Upload)**.
