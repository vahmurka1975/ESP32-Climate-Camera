# Проверка упаковки ESP32-Climate-Camera v1.2.0

Дата: 2026-10-12. Тип поставки: архив исходников для Arduino IDE 1.8.19.

## Выполненные проверки

- Все 12 необходимых файлов скетча присутствуют и не пусты.
- VERSION и FirmwareVersion.h содержат версию 1.2.0.
- Папка скетча и основной INO имеют одинаковое имя.
- Локальные include (13 ссылок) разрешаются внутри комплекта; Secrets.h допускается как необязательный личный файл.
- Два профиля TFT побайтно совпадают: ST7789, 240×240, SPI 20 МГц.
- Определения GPIO совпадают с приложенным ClimateCamera_20083363.cpp (1.0.4).
- Тела setFanDuty, setupFanPWM, updateFanControl побайтно совпадают с этим же исходником. Код ШИМ/ПИ вентилятора при упаковке не менялся.
- В комплекте присутствуют сетевой модуль, Web UI и обработчик Web OTA.
- Старые BIN, личный Secrets.h и внешние инструменты сборки в архив не включены.
- Состав файлов и SHA-256 проверяются tests/check_release.py; при публикации эта проверка выполняется на дереве проекта и повторно после распаковки ZIP.
- ZIP проверяется на ошибки CRC и небезопасные пути.

## Не выполнено

Полная компиляция Arduino-ESP32, host-компиляция с заглушками, создание нового BIN и испытания на ESP32 не выполнялись. Наличие кода Wi-Fi/OTA не является подтверждением работоспособности на устройстве. В среде упаковки не обнаружены arduino-cli, PlatformIO и компилятор ESP32.

Целевая конфигурация для самостоятельной сборки: классический ESP32 Dev Module, Arduino-ESP32 2.0.17, TFT_eSPI с профилем из архива. Первая загрузка с OTA-разметкой выполняется по USB. Перед загрузкой смените примерные пароли. Сборка и стендовые проверки необходимы до подключения нагрузок.

Функциональные отличия подготовленного исходника (в том числе Wi-Fi/Web OTA и ограничение работы компрессора) описаны в CHANGELOG.md; их не следует путать с простой проверкой неизменности GPIO и ШИМ.
