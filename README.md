# Климатическая камера на ESP32 (Версия 1.0.2)

Прошивка контроллера климатической камеры для колбас/сыров/вызревания продуктов на микроконтроллере **ESP32** и датчике **SHT31** (SHT30), с экраном **ST7789** (240×240 SPI).

## Основные возможности
- **Климат-контроль:** раздельное поддержание температуры (нагрев / охлаждение) и влажности (увлажнение / осушение компрессором).
- **ПИ-регулирование обдува:** ШИМ вентилятора 25 кГц (8 бит, инверсный сигнал) с обратной связью по тахометру.
- **Интерфейс:** цветной TFT дисплей 240x240, управление энкодером, меню настроек и графики.
- **Защита оборудования:** контроль минимальных пауз компрессора, защита от зависаний графики.

---

## Изменения в версии 1.0.2
1. **Индикация версии:** в нижней строке информационных экранов вместо служебной надписи выводится `ВЕРСИЯ 1.0.2`.
2. **Экран «Уставки климата» (Экран 4):** отображаются только ключевые параметры — температура, влажность, гистерезис температуры и гистерезис влажности.
3. **Защита компрессора холодильника:** задержка включения увеличена до **5 минут** (300 000 мс) как после старта питания, так и между повторными пусками.
4. **Импульсный режим увлажнителя:** при запросе на увлажнение реле работает циклом — **20 секунд включено, 2 минуты (120 секунд) пауза** до достижения уставки.
5. **Надежность TFT:** сохранен алгоритм периодического безопасного восстановления экрана и защиты от сбоев SPI.

## Инструкция по сборке и прошивке

### 1. Подготовка Arduino IDE 1.8.19
1. Установите ядро **esp32 by Espressif Systems** версии **2.0.17** (в *Инструменты -> Плата -> Менеджер плат*).
2. Выберите плату: **ESP32 Dev Module**.
3. Установите библиотеки через *Библиотеки -> Управлять библиотеками*:
   - `TFT_eSPI` (версия 2.5.43)
   - `Adafruit SHT31 Library` (версия 2.2.2)
   - `Adafruit BusIO` (версия 1.17.4)

### 2. Настройка дисплея (TFT_eSPI)
1. Закройте Arduino IDE.
2. Скопируйте файл `TFT_eSPI_setup/User_Setup.h` из этого репозитория в папку установленной библиотеки `TFT_eSPI` (обычно находится в `Документы/Arduino/libraries/TFT_eSPI/`), заменив оригинальный `User_Setup.h`.
3. Убедитесь, что в файле `TFT_eSPI/User_Setup_Select.h` раскомментирована только строка `#include <User_Setup.h>`.

### 3. Прошивка
1. Откройте файл `ClimateCamera_1_0_2_IDE1819/ClimateCamera_1_0_2_IDE1819.ino`.
2. Выберите нужный COM-порт.
3. Нажмите **Загрузить** (Upload). Скорость Serial Monitor: **115200 бод**.
