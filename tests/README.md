# Проверки релиза v1.2.0

Запуск из корня распакованного пакета: `python3 tests/check_release.py`.

Скрипт проверяет комплектность, версию, совпадение профилей TFT, отсутствие старых BIN и личного Secrets.h, а также SHA-256 всех файлов архива. После изменения исходников контрольные суммы нужно пересоздать.

При упаковке дополнительно сравнивались определения GPIO и тела функций setFanDuty, setupFanPWM, updateFanControl с приложенным исходником 1.0.4. Проверены локальные include и наличие сетевого/OTA-модуля. Это статические проверки, а не компиляция, проверка Arduino API или испытание устройства.

Компиляция ESP32, host-компиляция с заглушками и аппаратные испытания в этом процессе не выполнялись. Результаты и ограничения приведены в BUILD_REPORT.md.
