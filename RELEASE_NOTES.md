# Release notes — v1.2.1

В архиве находятся исходники проекта и скомпилированные бинарники для ESP32 Dev Module.

Перед прошивкой сделайте резервную копию действующей конфигурации. После загрузки откройте Serial Monitor на 115200 бод и проверьте сообщения SHT30 и вкладку «Журнал событий». Аппаратно проверьте реле без подключённых силовых нагрузок.
